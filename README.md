3. **Session 3 - Control Flow (If-Else)**: Pengkondisian logika dan alur keputusan program[cite: 1].
4. **Session 4 - Loops and Patterns**: Perulangan (`for` & `while`) serta pembuatan pola logika[cite: 1].
5. **Session 5 - Functions and Reusability**: Pembuatan fungsi, parameter/argumen, dan penerapan modul modular[cite: 1].
6. **Session 6 - List & Dictionaries**: Struktur data majemuk untuk pengelolaan koleksi data[cite: 1].
7. **Session 7 - File Handling and CSV**: Pembacaan, penulisan, dan pemrosesan file teks serta dataset CSV[cite: 1].
8. **Session 8 - End to End Python Project**: Integrasi seluruh materi dalam proyek pemrograman terpadu[cite: 1].
